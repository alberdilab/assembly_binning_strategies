# Assembly binning strategies
Main repository for the study *Different assembly and binning strategies recover contrasting genome catalogues and community profiles* (Eisenhofer, Alberdi and Aizpurua). It holds the most up-to-date code for the genome-resolved metagenomics pipeline and for every analysis, figure and number in the manuscript, and the source of the bookdown webbook.

Raw sequencing data are archived at the ENA under BioProject PRJEB77276.

## Repository structure

| Path | Content |
|---|---|
| `pipeline/` | Code that turns raw reads into the genome catalogues: preprocessing and subsampling notes (`primary_processing.md`), Snakemake workflows for multi-coverage binning (`cobinning.smk`) and multi-split binning (`vamb_multisplit.smk`), conda environments, output merging (`0_data_cleaning_merging.R`) and the downsampling targets (`downsampling/`). Paths to the original HPC are kept as used for the study and need adapting. |
| `*.Rmd` (root) | Analysis chapters of the webbook, in numbered order. |
| `data/` | Processed inputs for the chapters (dereplicated catalogue annotations, count tables, runtimes). `data/data.Rdata` is generated by `01_data_preparation.Rmd`. `data/taxonomy_tables` and `data/trees` hold raw tables and are not tracked by git. |
| `results/` | Outputs of the heavy computations (`alpha_diversity.Rdata`, `beta_diversity.Rdata`). |
| `figures/` | Hand-assembled figure files (Illustrator `.ai` and `.png`). |
| `misc_code/` | Helper scripts (GUNC parsing, bash snippets). |
| `docs/` | Rendered webbook. |

## Analysis procedures

The webbook is available at [alberdilab.github.io/assembly_binning_strategies](https://alberdilab.github.io/assembly_binning_strategies). It gives a user-friendly overview, while analyses can be reproduced directly from the Rmd documents. Code chunks that require heavy computation (alpha and beta diversity) are set to `eval=FALSE`, and their outputs are stored in `results/`. The chapter *Numbers reported in the manuscript* maps each statistic in the text to its chunk.

To re-render the webbook:

```r
library(bookdown)
library(htmlwidgets)
library(webshot)

render_book(input = ".", output_format = "bookdown::gitbook", output_dir = "docs")
```
