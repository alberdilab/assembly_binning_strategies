# Assembly binning strategies

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24074915.svg)](https://doi.org/10.5281/zenodo.24074915)

Main repository for the study *Different assembly and binning strategies recover contrasting genome catalogues and community profiles* (Eisenhofer, Alberdi and Aizpurua). It holds the most up-to-date code for the genome-resolved metagenomics pipeline and for every analysis, figure and number in the manuscript, and the source of the bookdown webbook.

Releases are archived at Zenodo. The DOI above ([10.5281/zenodo.24074915](https://doi.org/10.5281/zenodo.24074915)) always resolves to the latest version.

Raw sequencing data are archived at the ENA under BioProject PRJEB77276.

## Repository structure

| Path | Content |
|---|---|
| `pipeline/` | Code that turns raw reads into the genome catalogues: preprocessing and subsampling notes (`primary_processing.md`), Snakemake workflows for multi-coverage binning (`cobinning.smk`) and multi-split binning (`vamb_multisplit.smk`), conda environments, output merging (`0_data_cleaning_merging.R`) and the downsampling targets (`downsampling/`). Paths to the original HPC are kept as used for the study and need adapting. |
| `*.Rmd` (root) | Analysis chapters of the webbook, in numbered order, including the chapters that regenerate the manuscript figures (`10_manuscript_figures.Rmd`, `11_supplementary_figures.Rmd`). |
| `data/` | Processed inputs for the chapters (dereplicated catalogue annotations, count tables, runtimes). `data/data.Rdata` is generated by `01_data_preparation.Rmd`. `data/taxonomy_tables` and `data/trees` hold raw tables and are not tracked by git. |
| `results/` | Outputs of the heavy computations (`alpha_diversity.Rdata`, `beta_diversity.Rdata`). |
| `figures/` | Manuscript figures: Illustrator `.ai` and `.png` (Fig. 1, design), and the panels assembled from chapter *Manuscript figures* (`Figure2_v6`, `Figure3_v6`, `Figure4_v1`; `.svg`, `.pdf`, `.png`). `figures/supplementary/` holds Supplementary Figures S1-S7 generated by chapter *Supplementary figures*. |
| `misc_code/` | Helper scripts (GUNC parsing, bash snippets). |
| `docs/` | Rendered webbook. |

## Analysis procedures

The webbook is available at [alberdilab.github.io/assembly_binning_strategies](https://alberdilab.github.io/assembly_binning_strategies). It gives a user-friendly overview, while analyses can be reproduced directly from the Rmd documents. Code chunks that require heavy computation (alpha and beta diversity) are set to `eval=FALSE`, and their outputs are stored in `results/`.

To re-render the webbook:

```r
library(bookdown)
library(htmlwidgets)
library(webshot)

render_book(input = ".", output_format = "bookdown::gitbook", output_dir = "docs")
```

## Software versions

The webbook was last rendered with R 4.3.3, hilldiv2 2.0.5, tinytable 0.16.0 and bookdown 0.46. The tree plots (`ggtree`, `ggtreeExtra`, `ggnewscale`) need a ggtree release that supports the installed ggplot2: ggtree 3.10.1 does not work with ggplot2 4.0 (error `@mapping must be <ggplot2::mapping>`). Use either ggplot2 3.5.x with ggtree 3.10, or a newer ggtree release built for ggplot2 4.x (not tested here).
